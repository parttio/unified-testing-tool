What it shows

    

      
B is the floor
Dropping single() removes 9 words here and makes the API smaller: the 33 query types fold into their Wrappers.

      
Structure beats shortcuts
The biggest readability gain is a task method in the test class (27 words for the scenario), and it costs no API. Agents can write them; the rule set can't require them.

      
Comments read well but stay in the code
Given/when/then comments help the reviewer of the diff and cost nothing, but no report sees them. step(..) costs one static method and some lambda noise, and puts the sections into every report.

      
The report does the reading for non-developers
The User Step report names every component and value, so the code doesn't have to read like English for a product owner to follow the run.
