# Unreleased

What is on `main` and not in a release yet. Each change adds its release note as a file of
[`unreleased/`](unreleased/), and the documentation build assembles them into this page: read it on the
[documentation site](https://parttio.github.io/unified-testing-tool/releases/unreleased/), or run
`scripts/release_notes.py unreleased`.

Don't edit this file: every pull request would change it, and parallel ones would conflict. See
[`unreleased/README.md`](unreleased/README.md) for how to add a note.
