- **Write against the Unified API only:** `page.find(UnifiedX.class)` with filters, the Wrapper's actions, and `assertThat` from `com.vaadin.testing.unified.assertion.UnifiedAssertions`. Never name a Testing Tool in a test, unless the test needs one and declares it with `@RequiresTestingTool` ([When a test needs one Testing Tool](tool-specific.md)).
- **Find components the way a user does:** by type and label, accessible name or text. Use a test id only when there is nothing the user can read ([Finding components](finding-components.md)).
- **Match exactly one, never pick one.** There is no `first()`: when several components match, add a filter or a scope that names the one meant. `all()` is only for a loop over every match ([Several matches](finding-components.md#several-matches)).
- **Check state with `assertThat`**, not with getters and `assertEquals`: getters don't retry, and in a browser the update may arrive a moment later ([Assertions and waiting](assertions-and-waiting.md)).
- **Don't wait by hand.** Actions wait for the server and checks wait until they hold. No `Thread.sleep(..)`, no Testing Tool's own waits, and no longer timeout to make a test pass; `page.waitUntil(..)` only for a condition no check states.
- **Keep Wrappers, not values.** A Wrapper finds its component again on every call, so it never goes stale: declare a field's Wrapper once, use it for the whole test.
- **Name the scenario, and end on what the user sees:** `@DisplayName` with a sentence, `page.step(..)` around a piece of user work, and a check after the last action ([Structuring a scenario](structuring-a-scenario.md)).
- **Look the API up, don't guess it:** every Wrapper's filters, actions, reads and checks are in `META-INF/unified/api-reference.md` inside the `unified-test-api` jar, of the version you use. Read it there instead of decompiling the jar.
- **Leave other tools' habits behind:** TestBench `$(..).first()`, Browserless `test(..)` and `roundTrip()`, Playwright `page.locator("css")` ([Common mistakes](common-mistakes.md)).
